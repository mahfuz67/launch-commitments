The exact boundary

Contributions fund the published first DBC purchase, or remain recoverable under the campaign’s refund rules. After settlement, contributors hold tokens exposed to trading losses. Organizer-paid setup costs are separate from refundable principal.

Retained upgrade authority: this test program can be replaced by its authority. It is not audited. Campaign rules alone do not eliminate that trust assumption.

Reproduce and compare

The repository contains the runnable app, SDK, program source, bytecode, test harness and a recovery tool that needs only an RPC connection and the contributor’s own key. The app runs locally against the public devnet deployment.

What this proof does not establish
  • Public trading on the curve, graduation and DAMM v2 migration: not run on devnet in this proof. Tested against a local validator only (tests/devnet-api.cjs).
  • Signing with a real wallet extension, any participant outside the build team, and any mainnet use.
  • Security against every adversarial condition, customer demand, or prize placement.
